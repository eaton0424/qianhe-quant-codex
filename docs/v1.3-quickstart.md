# V1.3 Quickstart

## V1.3 定位

V1.3 是**本地量化数据库与数据接入层**，用于把以下内容统一沉淀到本地：

- 行情数据
- 新闻事件
- 公告事件
- 财务数据
- 因子结果
- 回测结果
- 数据质量日志

默认数据库路径：

- `data/local_db/qianhe_quant.duckdb`

也支持通过环境变量覆盖：

- `QIANHE_QUANT_DB_PATH`

---

## 1. 初始化数据库

```powershell
python -m qianhe_quant.cli db-init
```

---

## 2. 导入本地日线 CSV

```powershell
python -m qianhe_quant.cli db-import-ohlcv --csv qianhe_quant/data/sample_ohlcv.csv --symbol SAMPLE
```

说明：

- `--csv`：本地行情 CSV 路径
- `--symbol`：写入数据库时使用的标识

如果 CSV 没有 `amount` 字段，系统会自动用：

- `close * volume`

进行估算，并在输出中标注 warning。

---

## 3. 查看数据库状态

```powershell
python -m qianhe_quant.cli db-status
```

这个命令会输出：

- 数据库路径
- 是否初始化
- 当前表清单
- `market_daily` 行数
- `symbols` 数量
- `data_quality_logs` 数量
- 最近一次导入结果

同时会生成报告：

- `reports/local_database_status_report.md`

---

## 4. 导出标准 OHLCV

```powershell
python -m qianhe_quant.cli db-export-ohlcv --symbol SAMPLE --out qianhe_quant/data/sample_ohlcv_from_db.csv
```

用途：

- 从数据库导出标准 OHLCV
- 继续喂给现有回测和策略实验室

---

## 5. 用导出的数据库数据跑回测

```powershell
python -m qianhe_quant.cli backtest --data qianhe_quant/data/sample_ohlcv_from_db.csv --strategy ma_cross
```

---

## 6. 直接从数据库跑回测

```powershell
python -m qianhe_quant.cli db-backtest --symbol SAMPLE --strategy ma_cross
```

---

## 7. 查看报告

当前最重要的数据库与策略报告包括：

- `reports/local_database_status_report.md`
- `reports/strategy_tournament_report.md`
- `reports/weekly_strategy_lab_report.md`

---

## 8. 本地数据库路径

- `data/local_db/qianhe_quant.duckdb`

---

## 9. 不能提交到 GitHub 的文件

不要上传：

- `data/local_db/*.duckdb`
- `data/local_db/*.wal`
- `.env`
- 交易密码
- API 私钥
- Token

可以上传：

- schema
- ingestion 脚本
- 配置文件
- 样例 CSV
- 测试
- 文档
- Markdown 报告

---

## 10. 备份方法

代码备份：

```powershell
git bundle create qianhe-quant-v1.3.bundle main v1.3.0-local-database
```

数据库备份：

- 复制 `data/local_db/qianhe_quant.duckdb`
- 建议放到单独的 `backup` 目录

---

## 11. 风控边界

当前系统仍然严格限制为：

- 不做实盘
- 不接券商 API
- 不保存交易密码、API 私钥、Token
- 不自动下单
- 不输出买入、卖出、仓位、收益承诺

所有输出只允许称为：

- 研究信号
- 模拟组合
- 回测结果
- 数据质量报告
- 风险提示
