# 视频内容工程化拆解

## 视频一：AI Agent + 交易 API + Skill + 定时任务

工程启发：

- 交易能力应被拆成独立 Skill，而不是散落在聊天里。
- 行情、账户、下单、撤单、日志、汇报应分别封装。
- 先做模拟交易，再考虑人工确认后的半自动化流程。
- 自动汇报比自动下单更适合当前阶段。

## 视频二：从主观到量化，普通工科生的进阶路径

从可见主题提炼的工程路线：

- 先理解主观投资逻辑。
- 再把逻辑拆成变量、条件、规则。
- 用 Python/Pandas 做数据验证。
- 用回测证明或证伪观点。
- 用风控规则限制策略幻觉和过拟合。

## 合并后的系统定位

本项目不是“AI 自动炒股工具”，而是：

```text
主观投研逻辑工程化工具
+ 策略回测工具
+ 模拟交易工具
+ 风控留痕工具
+ Codex 可持续迭代代码仓库
```
