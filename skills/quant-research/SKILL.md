# Quant Research Skill

When the user describes a market view, theme, stock, or subjective trading idea:

1. Rewrite it into a hypothesis.
2. Identify observable variables.
3. Define data fields required.
4. Convert the idea into signal rules.
5. Mark assumptions and risk points.
6. Never produce live trading instructions.

Output format:

- Hypothesis
- Required data
- Signal rule
- Backtest plan
- Risk checks
- Open verification tasks
